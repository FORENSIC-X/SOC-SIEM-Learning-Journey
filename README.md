# SOC-SIEM-Learning-Journey
My first-person documentation of learning SOC analysis and SIEM from scratch using only free tools. Wazuh as the core SIEM, plus Splunk Free, Sysmon, auditd, Suricata, Zeek and Sigma. Lab-only attacks from Kali are detected, investigated and documented: lessons, labs, detection rules, queries, playbooks, hunts and writeups.
